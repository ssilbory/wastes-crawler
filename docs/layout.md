# Repository layout

A map of where things live and what each area holds. Read this before
searching the tree. Keep it current when adding or moving a directory or a
group of modules; single new files in an existing group need no entry.

Snapshot: 2026-10-26, about 1,120 tracked files.

## src/ (layered; see AGENTS.md for import rules)

No runtime import cycles: `tests/architecture.test.ts` checks the whole tree (type-only imports don't count). The world's event bus is inverted to keep it that way: emitters import `world/bus.ts`, and the listener table from `world/listeners.ts` reaches `emit` through `GameData.listeners`.

Entry: `src/main.ts` → `src/ui/Shell.tsx`, which routes by URL hash: `#/world` (game), `#/arena`, `#/editor` (level editor), `#/maps` (overland map editor), `#/settings`, `#/help`, `#/about`, `#/builder` (the Characters page), default the title screen. `#/world/continue` and `#/world/starters` (`src/ui/world/launch.ts`) are the title screen's requests to the Overland.

## tests/ (Vitest)

About 265 `*.test.ts` files mirroring `src/`: `tests/rules/`, `tests/game/` (with `combat/`, `dungeon/`, `factions/`, `world/` subfolders), `tests/render/`, plus top-level content and SRD integrity tests (`*-content.test.ts`, `srd-*.test.ts`, `data-check-edges.test.ts`) and `architecture.test.ts` (fails, naming the loop, on any runtime import cycle in `src/`). `tests/campaign/` holds a headless campaign driver and its end-to-end campaign test. Shared helpers: `tests/helpers/scripted-rng.ts` (forces exact die faces) and `helpers*.ts` in each game subfolder.

## e2e/ (Playwright)

One `*.spec.ts` per player-facing feature (builder, wizard, dungeon, town, quests, magic, mounts, factions, persistence, endgame, mobile (phone layout, install, offline), and others), `wizard.ts` helper, and screenshot baselines in `dungeon.spec.ts-snapshots/`.
