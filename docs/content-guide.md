# Content guide

Every piece of content is a JSON record with a zod schema and a stable id, so Claude can generate and validate content without touching engine code. A level validator checks references, reachability, and that every quest can be completed.

## Levels

**Map format.** Walls sit on cell edges, not in cells, as in Wizardry and Bard's Tale. Levels are authored as a doubled ASCII grid that Claude can write, diff, and validate: cells at odd coordinates, edges between them. Glyphs mark feature positions; details live in the level JSON keyed by coordinate.

```
+-+-+-+
|. . <|
+d+-+ +
|T .sN|
+-+-+-+
```

`-` and `|` are walls, a space is open, `d` is a door, `s` is a secret door, `<` is stairs up, and `T` and `N` are a trap and an NPC.

## Content types

| Content type     | Key fields                                                                                                                                                        | Notes                                                                                                                                                                                                                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| People           | Attribute modifiers, optional lineages with their own modifiers, signature racial foci, racial foci pick list, size, armor rules                                  | Goblins, Orcs, Elves, Centaurs (four lineages), Beastmen, Gnomes                                                                                                                                                                                                                                       |
| Background       | Free skill, Growth and Learning tables, optional peoples list, starting gear, flavor                                                                              | Authored for the setting; the SRD has only a handful. Without a peoples list, a background is open to every people                                                                                                                                                                                     |
| Racial focus     | Name, description, level texts, optional bonus skill                                                                                                              | A people's signature focus, in the SRD focus format; listed by the people or lineage                                                                                                                                                                                                                   |
| Focus rule       | SRD focus id, availability (pickable, later, excluded), category (combat, non-combat, both), bonus skill, Developed Attribute and Die Hard flags, sheet effects   | One per SRD focus; the bonus skills must match the SRD text, which a test checks                                                                                                                                                                                                                       |
| Shield           | Base AC, bonus, cover, cost, encumbrance                                                                                                                          | The house shields, which override the SRD shield rows                                                                                                                                                                                                                                                  |
| Starting package | Items with quantity and location (worn, readied, stowed), crowns                                                                                                  | Sized for the character's people when chosen                                                                                                                                                                                                                                                           |
| Equipment rules  | Barding multipliers, weapons without the unskilled penalty, the Numerous trait, starting crowns dice                                                              | One object in equipment-rules.json                                                                                                                                                                                                                                                                     |
| Tradition        | Bonus skill, spell lists, Effort skills and attributes                                                                                                            | High Mage and Elementalist so far; arts share the tradition id                                                                                                                                                                                                                                         |
| Class option     | Progression id, display name, and for Mages their traditions (full or partial, arts table), spell-slot table, and starting spell count                            | The classes a new character can take                                                                                                                                                                                                                                                                   |
| Monster          | SRD stat line, Instinct behaviors, reach and flying tags, portrait, XP value, loot dice, component drops                                                          | SRD monsters imported; new ones authored in the same shape                                                                                                                                                                                                                                             |
| Monster combat   | SRD monster id, assigned SRD weapon for Wpn damage, tags (flying, reach, unliving, metal)                                                                         | One entry per SRD monster, and a weapon for every Wpn monster; a content test checks both                                                                                                                                                                                                              |
| Combat magic     | Source spell or art id, target (enemy, enemy row, ally, other ally, self, none), Effort (scene, day, committed), limit (scene, once per target per scene), effect | The spells and arts the combat engine can use; each effect kind is implemented in src/game/combat/spells.ts                                                                                                                                                                                            |
| Encounter table  | Weighted entries, each hostile or wary, of monster groups with a fixed number or dice and an enemy row                                                            | One per terrain so far (data/content/encounter-tables.json); later per dungeon level, zone, or region                                                                                                                                                                                                  |
| Terrain          | Glyph, movement (open, difficult, impassable), forage and hunt difficulties, water, harsh nights, encounter table                                                 | data/content/terrains.json                                                                                                                                                                                                                                                                             |
| Region           | Terrain and danger glyph rows in odd-q hex layout, sites, starting town                                                                                           | data/content/regions.json. Overlay glyphs: `=` road, `.` ordinary, `!` dangerous                                                                                                                                                                                                                       |
| Mishap           | Table (travel or camp), weight, text, effect (end the march, damage, strain, rations, no recovery, extra encounter check)                                         | data/content/mishaps.json                                                                                                                                                                                                                                                                              |
| Overland rules   | Encounter dice by danger, forage and hunt steps, months and seasons, start date                                                                                   | data/content/overland-rules.json                                                                                                                                                                                                                                                                       |
| Fixed encounter  | Coordinate, monsters, reaction override, one-shot flag                                                                                                            | Guardians, set pieces, bosses                                                                                                                                                                                                                                                                          |
| Trap             | Notice difficulty, disarm skill and difficulty, save type, effect                                                                                                 | Pits, darts, gas, alarms, teleport traps                                                                                                                                                                                                                                                               |
| Ally / hireling  | Class, level, loyalty, cost, slot size (1 or 2), join conditions                                                                                                  | Recruitable in town or found in the dungeon. Giants and dragons take two slots                                                                                                                                                                                                                         |
| Rescue target    | Location, captors, escort rules, reward, quest link                                                                                                               | Creatures or people to free and bring back. Occupies an NPC slot while escorted                                                                                                                                                                                                                        |
| Mission giver    | Location, quests offered, prerequisites, dialogue                                                                                                                 | Town NPCs and in-dungeon NPCs. Regardless of the pool, 25% of crowns spent with a craftsman count toward the town's spending threshold |
| Quest            | Objectives, triggers, state flags, rewards, failure conditions, PC slot replacements                                                                              | Driven by an event bus from the game layer                                                                                                                                                                                                                                                             |

| Dialogue         | Nodes, choices, skill checks, flag effects                                                                                                                        | Kept small; reaction result picks the entry node                                                                                                                                                                                                                                                       |
